# Audit — LDL-analysis- (September 2026)

**Branch:** `audit_v1-202609` · **Date:** 2026-09-23 · **Scope:** Braian's checklist:

1. Audit the code.
2. Can 3 LDL-C cut-offs replace the 5?
3. Are the statistical tests used appropriately?

All figures below come from the ADNI analysis cohort (age ≥ 65, non-missing LDL-C):
**347 participants, 1819 visits**. This is cognitively unimpaired only (CN 259, SMC 88);
94 participants are A+. Decision and fact identifiers (`D-NNN`, `F-NN`) refer to
`DECISIONS.md` and the local working file.

## Bottom line

- **The code is now reproducible and gives the same numbers as the original.** The refactored
  pipeline reproduces `Code_LDL_cutoffs.R` to machine precision. That covers every
  coefficient, standard error, p-value and type III F of all six mixed models (max
  difference 2.5e-12), plus the Kruskal–Wallis tests and group counts.
- **Three groups are better than five.** Merging the three classes at or above 130 mg/dL
  (`<2.6 / 2.6–3.3 / ≥3.3` mmol/L) costs no model fit and removes the cells of 1–3
  participants. It is now a sensitivity run. Continuous LDL-C fits better than any grouping.
- **The tests are broadly appropriate, with three things to fix before publication:**
  - The longitudinal Aβ model silently drops the censored `">1700"` values, almost all from A−
    participants.
  - The significance bars on Figures 1d–1f are unadjusted Wilcoxon tests, which don't match
    the Dunn tests reported.
  - The 5-group three-way interaction is estimated from cells of 1–3 people.
- **The findings are null.** No LDL-C × time or LDL-C × amyloid × time effect reaches
  p < 0.05, under any grouping or with continuous LDL-C. The one nominal signal (baseline
  p-tau, § 3.3) does not survive multiple-testing correction.

## 1. Code audit

### 1.1 Problems in the original script (all fixed in the refactor)

| # | Problem | Consequence |
|---|---|---|
| 1 | Hard-coded Windows path to the data file | The script only ran on one machine |
| 2 | `library(lsmeans)`, `library(tidymv)`, `library(medmod)`: not installed here, and never used | The script stopped at line 17 on a fresh machine |
| 3 | 27 packages loaded, about 8 actually used | Slow start-up and a long list of masking warnings; results depend on load order (e.g. `MASS::select` vs `dplyr::select`) |
| 4 | `install.packages()` inside the analysis script | Installs silently mid-run, unpinned version |
| 5 | The LDL-C `cut()` repeated three times with the labels copied by hand | Three copies could drift apart |
| 6 | Figures and tables printed to screen, never saved | Results not reproducible from a clean run |
| 7 | Censored assay strings (`">1700"`, `"<8"`) turned into NA by `as.numeric()`, with only R's generic warning | Silent data loss. See § 3.4, the most important finding |

The refactor adds a single config file (`Scripts/config_ldl_analysis.R`), 11 function modules,
two runners, `renv` package pinning, and gitignored `Data/` and `Outputs/`. The ADNI data is
never committed.

### 1.2 Bugs found by the code review of the refactor (all fixed)

An independent review found no bug that changes current results. It found these, now fixed:

| # | Bug | Failure scenario | Fix |
|---|---|---|---|
| 1 | Runner crashed when run line by line | RStudio *Run all* or piping into R: `sys.frame(1)` error, "not that many frames" | Safe frame search; falls back to `LDL_ANALYSIS_ROOT` / working directory |
| 2 | `--file=` took priority over the sourced file's path | A master script run by `Rscript` that `source()`s a runner: config not found | The sourced file is checked first |

| 4 | One empty group removed **all** significance bars | A subgroup with 0–1 people in "Very high": ggsignif drops the whole layer | Untestable pairs are skipped with a warning |
| 5 | Bar heights fixed at 4 values | A 3-group scheme put bars in the wrong place | Heights computed as start + step × comparison |
| 6 | Literal `≥` in the config | Garbled labels under non-UTF-8 locales (older R on Windows) | `\u2265` escape, as in the original |
| 7 | LDL-C converted to numeric *after* the missing-value filter | A text LDL-C value would have stayed in as an NA group | Coerce, then filter |

### 1.3 Behaviour kept from the original on purpose (needs a decision)

- **Figure 1f clips its axis with `scale_y_continuous(limits = c(-8, 8))`.** This *removes*
  one participant before the box statistics and the Wilcoxon bars are computed. Figures 1d/1e
  lose nobody. Switching to `coord_cartesian()` only zooms and keeps the participant
  (`limit_mode = "coord"` in the config).
- **The mmol/L cut-points are rounded:** 2.6 / 3.3 / 4.1 / 4.9. The exact conversion of
  100 / 130 / 160 / 190 mg/dL is 2.59 / 3.36 / 4.14 / 4.91, and the common convention for
  130 mg/dL is 3.4. Six baseline participants change class under the exact conversion, four of
  them in [3.3, 3.36).
- **Table 1 uses `ABETA_to_use` / `PTAU_to_use`, while the tests use `*_bl_to_use`.** The
  values agree, but the former are missing for 10 participants, so Table 1 describes 337 where
  the tests use 347.
- **Five baseline LDL-C values are below 0.04 mmol/L** (next lowest 0.14). That is
  physiologically implausible and probably an entry or unit error. They sit in "Optimal".

## 2. Three cut-offs instead of five?

### 2.1 The problem with five

| LDL-C group (mmol/L) | A− | A+ | Total |
|---|---|---|---|
| Optimal < 2.6 | 134 | 50 | 184 |
| Near optimal 2.6–3.3 | 83 | 26 | 109 |
| Borderline high 3.3–4.1 | 30 | 13 | 43 |
| High 4.1–4.9 | 5 | 3 | 8 |
| Very high ≥ 4.9 | **1** | **2** | 3 |

The longitudinal models estimate an LDL-C group × amyloid × time interaction. For "Very high",
that means one slope from 1 person and another from 2. The estimates exist, but they are noise:
the Very-high ribbon in the trajectory figure spans the whole y-axis.

### 2.2 Candidate 3-group schemes

| Scheme | Cut-points (mmol/L) | Baseline n | A+ n | Smallest cell | Comment |
|---|---|---|---|---|---|
| **ncep3 (recommended)** | < 2.6 / 2.6–3.3 / ≥ 3.3 | 184 / 109 / 54 | 50 / 26 / 18 | 18 | NCEP classes; "≥ 130 mg/dL" is a standard clinical threshold |
| NCEP, merge top two | < 2.6 / 2.6–4.1 / ≥ 4.1 | 184 / 152 / 11 | 50 / 39 / 5 | 5 | Top group still too small |
| Treatment target | < 1.8 / 1.8–2.6 / ≥ 2.6 | 60 / 124 / 163 | 18 / 32 / 44 | 18 | 70 mg/dL target; asks a different question (treated-to-target) |
| Tertiles | < 2.19 / 2.19–2.81 / ≥ 2.81 | 116 / 115 / 116 | 31 / 31 / 32 | 31 | Balanced but sample-specific; not clinically interpretable |

### 2.3 Does merging lose information?

These are likelihood-ratio tests of the nested 3-group model against the 5-group model (ML
fits, same covariates and random effects). A high p means the extra two groups add nothing.
ΔAIC and ΔBIC are relative to the best model for that outcome, so lower is better.

| Outcome | LRT ncep3 vs 5 groups | ΔAIC 5 groups | ΔAIC ncep3 | ΔAIC continuous | ΔBIC 5 groups | ΔBIC ncep3 |
|---|---|---|---|---|---|---|
| mPACCtrailsB | χ² = 1.62, df 8, **p = 0.99** | 19.3 | 5.0 | 0 | 85.4 | 27.0 |
| CSF p-tau | χ² = 3.56, df 8, **p = 0.89** | 13.5 | 1.1 | 0 | 68.1 | 19.3 |
| CSF Aβ42 | χ² = 2.33, df 8, **p = 0.97** | 23.9 | 10.2 | 0 | 75.5 | 27.4 |

- **Yes, three cut-offs are possible, and better.** The 5-group model is never better than the
  3-group model, and it costs 8 extra parameters.
- **Continuous LDL-C has the lowest AIC and BIC for every outcome.** A natural spline with
  3 df does not beat the linear term, so there is no sign of a threshold effect that grouping
  would capture. For the primary analysis, continuous LDL-C is the strongest choice. Clinical
  groups remain useful for description and figures.

### 2.4 What changed in the pipeline

The 3-group scheme is a **sensitivity run** (D-003). It never overwrites the primary 5-group
outputs:

```sh
LDL_SCHEME=ncep3 Rscript Scripts/run_cross_sectional.R   # -> Outputs/cross_sectional_ldl3/
LDL_SCHEME=ncep3 Rscript Scripts/run_longitudinal.R      # -> Outputs/longitudinal_ldl3/
```

The ncep3 results are as null as the 5-group ones:
- **Baseline Kruskal–Wallis:** p = 0.78 (Aβ42), 0.19 (p-tau), 0.87 (mPACC).
- **LDL-C group × amyloid × time:** p = 0.48 (mPACC), 0.21 (p-tau), 0.31 (Aβ42).
- **The one nominal signal** is in § 3.3.

## 3. Are the statistical tests appropriate?

### 3.1 Baseline comparisons: Kruskal–Wallis + Dunn

**Appropriate as a first look.** The outcomes are skewed and Aβ42 has a ceiling at 1700: 91
participants (26%) sit exactly at the cap. That rules out a plain ANOVA, and a rank test
handles the ties. But:

- **The tests are unadjusted.** Age, sex, APOE ε4 and education are not accounted for at
  baseline, although they are in every longitudinal model. We checked: an adjusted linear
  model gives the same answer (group F-test p = 0.71 / 0.56 / 0.71; continuous LDL-C
  p = 0.73 / 0.21 / 0.30). The conclusion does not change, but reviewers will ask. Residuals of
  the adjusted models are non-normal (Shapiro p < 1e-7 for CSF), so use log(p-tau) or robust
  standard errors if adjusted results are reported.
- **The groups are ordered, but the tests ignore that.** A trend test (Jonckheere–Terpstra, or
  Spearman on continuous LDL-C: ρ = −0.01 / 0.04 / −0.04, all p > 0.49) is more powerful for a
  dose–response question.
- **Dunn p-values are one-sided.** `dunn.test` reports Pr(Z ≥ |z|) and rejects at α/2. If the
  paper reports them as p-values, double them (or use `altp = TRUE`) to get two-sided values.
  The output columns are now named `p_one_sided` so this cannot be missed.

### 3.2 The significance bars in Figures 1d–1f

**Not appropriate as they stand.** The bars run **unadjusted** two-group Wilcoxon tests
between adjacent groups (`ggsignif`). The text reports Bonferroni-adjusted Dunn tests on
pooled ranks. These are different tests with different multiplicity, so a figure and its
caption can disagree. Here every bar reads NS either way, with unadjusted p between 0.056 and
0.98, so nothing is currently wrong. The inconsistency would matter as soon as one comparison
crossed 0.05.

**Recommendation:** annotate with the adjusted Dunn p-values (`Outputs/*/dunn_pairwise.csv`),
or drop the bars and report the omnibus test in the caption.

### 3.3 Longitudinal mixed models

**Well specified overall.** The random intercept and slope per participant suit visits that
are irregular and unbalanced (2–8 visits, median follow-up 4.7 years). All six models
converge, none is singular, and the estimates agree with the `bobyqa` optimizer to 5e-5.
Satterthwaite-df type III tests (`lmerTest`) are a sound choice. Residual skew is acceptable
(−0.54 to 0.08). Issues:

1. **Sparse cells in the 5-group interaction.** See § 2.1. It is the main reason to prefer
   3 groups or continuous LDL-C.
2. **Multiplicity.** There are three outcomes × two exposures × four LDL-C terms. Name one
   pre-specified primary test, for example LDL-C × amyloid × time on mPACC, and treat the rest
   as secondary.
3. **The one nominal signal.** In the p-tau model, the LDL-C group × amyloid term (a
   **baseline level** difference, not a slope) is p = 0.006 under ncep3 and p = 0.055 under
   5 groups. Among A+ participants, median baseline p-tau falls with LDL-C (30.4 / 27.3 / 23.4
   pg/mL), while A− participants are flat. This does not survive Bonferroni across the 12
   LDL-C terms (threshold 0.0042), has no time component, and could reflect statin use. Report
   it as exploratory at most.
4. **The Aβ42 model is partly circular.** The effect modifier `ABETA_positivity_ratio` is
   defined from the p-tau/Aβ42 ratio, and the outcome is Aβ42 itself. The A+ and A− groups
   therefore differ in the outcome by construction. The LDL-C × time terms stay interpretable;
   the amyloid terms of this model are not.
5. **Random-effects structure differs.** The Aβ42 models use a random intercept only, while
   the others use intercept and slope. If this was done for convergence, say so. Otherwise use
   the same structure for all three outcomes.
6. **Confounding by lipid-lowering treatment.** Participants with hyperlipidaemia (`HLP`, 55%)
   have *lower* LDL-C (median 2.42 vs 2.78 mmol/L), which points to statins. Adjusting for
   `HLP` changes the interaction p-values by less than 0.01, but `HLP` is a weak proxy. ADNI
   medication records (RECCMEDS) would allow a proper statin adjustment or stratification.
   Low LDL-C in treated people is a different exposure from low LDL-C in untreated people.

### 3.4 Censored CSF values: the most important issue

The longitudinal `ABETA` column holds the string `">1700"` in 161 visits (and `"<200"` in 1).
`PTAU` holds `"<8"` in 7. `as.numeric()` turns these into missing values, so they drop out of
the longitudinal Aβ42 and p-tau models.

The missingness is **not random**:

| | A− (n = 253) | A+ (n = 94) |
|---|---|---|
| Participants with ≥ 1 `">1700"` Aβ42 visit | **100 (40%)** | 1 (1%) |

The model loses the highest Aβ42 values almost entirely from the A− group. That biases the A−
trajectories downward and distorts every A− vs A+ contrast in the Aβ42 model. The model
currently fits 544 visits from 271 participants, when 706 visits carry an Aβ42 value.

The baseline column `ABETA_bl_to_use` handles the same censoring differently: it caps values
at 1700 (91 participants). So the cross-sectional and longitudinal analyses disagree on how to
treat the same assay limit.

**Options, in order of preference:**
1. A censored (Tobit) mixed model that treats `>1700` as "at least 1700"
   (e.g. `GLMMadaptive::mixed_model(family = censored.normal())`).
2. Substitute the limit (1700, 200, 8) and add a sensitivity analysis. This is simple, and it
   is how the baseline column already works.
3. Use Aβ42 values without the ceiling. 1700 pg/mL is the upper end of the Elecsys
   measuring range; check whether the ADNI UPENN release for these visits carries values
   extrapolated beyond it.

The pipeline now warns about the lost values on every run. It does not change them until this
is decided.

## 5. How to reproduce

```sh
Rscript -e 'renv::restore()'
Rscript Scripts/run_cross_sectional.R && Rscript Scripts/run_longitudinal.R
LDL_SCHEME=ncep3 Rscript Scripts/run_cross_sectional.R && LDL_SCHEME=ncep3 Rscript Scripts/run_longitudinal.R
```

The data file (`Data/cognition_LDL_C.xlsx`, ADNI DUA) is not in the repository; each
collaborator keeps a local copy. The scheme comparison (§ 2.3), the adjusted baseline models
(§ 3.1) and the censoring table (§ 3.4) were run as one-off audit checks. They are not part of
the pipeline.
