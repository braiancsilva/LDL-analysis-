Kept from the original on purpose (needs a decision)

  • Figure 1f clips its y-axis with scale_y_continuous(limits = c(-8, 8)). That removes one participant before the box statistics and Wilcoxon bars are computed. Zooming with coord_cartesian() would keep them in.
  • The mmol/L cut-points are rounded. 100 / 130 / 160 / 190 mg/dL convert exactly to 2.59 / 3.36 / 4.14 / 4.91 mmol/L, and 3.4 is the usual convention for 130 mg/dL. Six participants change class under the exact conversion, four of them in [3.3, 3.36).
  • Table 1 uses different CSF columns from the tests. It uses ABETA_to_use / PTAU_to_use, the tests use *_bl_to_use. The values agree, but the Table 1 columns are missing for 10 participants, so it describes 337 people where the tests use 347.
  • Five baseline LDL-C values are below 0.04 mmol/L (the next lowest is 0.14). That is physiologically implausible, so check them at source.

2Three cut-offs instead of five?

Baseline participants per LDL-C group, split by amyloid status. The longitudinal models estimate one slope per cell.

With five groups, “Very high” holds 1 A− and 2 A+ participants. The three-way interaction then estimates one slope from one person and another from two. That is why the Very-high ribbon in the trajectory figure spans the whole y-axis.

Does merging lose information?

The likelihood-ratio test compares the nested 3-group model with the 5-group model, using ML fits with the same covariates and random effects. A high p means the two extra groups add nothing. ΔAIC and ΔBIC are measured from the best model for each outcome, so lower is better.

  • Three cut-offs are possible, and better. The 5-group model never outperforms the 3-group one and costs 8 extra parameters.
  • Continuous LDL-C has the lowest AIC and BIC for every outcome. A natural spline with 3 df does not beat the linear term, so there is no threshold effect for grouping to capture. Continuous LDL-C is the strongest primary exposure. Clinical groups remain useful for description and figures.

The 3-group scheme runs as a sensitivity analysis and never overwrites the primary 5-group outputs:

3Are the statistical tests appropriate?

3.1 Baseline comparisons: Kruskal–Wallis + Dunn

Appropriate as a first look. The outcomes are skewed, and 91 participants (26%) sit exactly at the Aβ42 ceiling of 1700 pg/mL. That rules out a plain ANOVA, and a rank test handles the ties. Three caveats:

  • The tests are unadjusted. The baseline comparisons ignore age, sex, APOE ε4 and education, although every longitudinal model includes them. An adjusted linear model gives the same answer: group F-test p = 0.71 / 0.56 / 0.71, continuous LDL-C p = 0.73 / 0.21 / 0.30. The CSF residuals are non-normal, so any adjusted results should use log(p-tau) or robust standard errors.
  • The groups are ordered, but the tests ignore the order. A trend test is more powerful for a dose–response question. Spearman on continuous LDL-C gives ρ = −0.01 / 0.04 / −0.04, all p > 0.49.
  • Dunn p-values are one-sided. dunn.test reports Pr(Z ≥ |z|) and rejects at α/2. Double them, or use altp = TRUE, before reporting them as ordinary p-values.

3.2 Significance bars in Figures 1d–1f

Not appropriate as they stand. The bars come from unadjusted two-group Wilcoxon tests between adjacent groups. The text reports Bonferroni-adjusted Dunn tests on pooled ranks, so a figure and its caption can disagree. Every bar currently reads NS either way (unadjusted p between 0.056 and 0.98). The mismatch would show as soon as one comparison crossed 0.05.

Recommendation: annotate the figures with the adjusted Dunn p-values, or drop the bars and put the omnibus test in the caption.

3.3 Longitudinal mixed models

Well specified overall.

  • A random intercept and slope per participant suits irregular, unbalanced visits (2–8 per person, median follow-up 4.7 years).
  • All six models converge and none is singular. The estimates agree with the bobyqa optimizer to 5 × 10⁻⁵.
  • The Satterthwaite type III tests from lmerTest are sound.

Six issues remain:

  1. Sparse cells. The 5-group interaction relies on cells of 1–3 people (§2). This is the main reason to prefer 3 groups or continuous LDL-C.
  2. Multiplicity. Three outcomes × two exposures × four LDL-C terms give many tests. Pre-specify one primary test, for example LDL-C × amyloid × time on mPACC, and treat the rest as secondary.
  3. One nominal signal. In the p-tau model, the LDL-C group × amyloid term is p = 0.006 under ncep3 (p = 0.055 with 5 groups). It is a baseline level difference, not a slope. Among A+ participants, median baseline p-tau falls as LDL-C rises (30.4 → 27.3 → 23.4 pg/mL), while A− participants are flat. It does not survive Bonferroni across the 12 LDL-C terms (threshold 0.0042), has no time component, and could reflect statin use. Report it as exploratory at most.
  4. The Aβ42 model is partly circular. The amyloid modifier is defined from the p-tau/Aβ42 ratio, and the outcome is Aβ42 itself. The LDL-C × time terms stay interpretable, but the amyloid terms of this model do not.
  5. The random effects differ between models. The Aβ42 models use a random intercept only. If that was done for convergence, say so; otherwise use one structure for all three outcomes.
  6. Lipid-lowering treatment may confound LDL-C. The 55% of participants with hyperlipidaemia (HLP) have lower LDL-C (median 2.42 vs 2.78 mmol/L), which suggests statin treatment. Adjusting for HLP moves the interaction p-values by less than 0.01, but HLP is a weak proxy. ADNI medication records (RECCMEDS) would allow a proper adjustment or stratification.

3.4 Censored CSF values: the most important issue

HighThe Aβ42 model loses the highest values, almost all from A− participants

The longitudinal ABETA column holds the string ">1700" in 161 visits. as.numeric() turns them into missing values, and they drop out of the model. The model fits 544 of the 706 visits that carry an Aβ42 value.

100 / 253
A− participants with at least one >1700 visit (40%)
1 / 94
A+ participants with at least one >1700 visit (1%)

This missingness is not random. It biases the A− trajectories downward and distorts every A− vs A+ contrast in the Aβ42 model. The baseline column handles the same limit differently: it caps values at 1700 (91 participants). PTAU has the same problem with 7 "<8" values.

Options, in order of preference:

  1. A censored (Tobit) mixed model that treats >1700 as “at least 1700”, e.g. GLMMadaptive::mixed_model(family = censored.normal()).
  2. Substitute the assay limit (1700, 200, 8) and add a sensitivity analysis. This is simple, and it matches how the baseline column already works.
  3. Use uncapped values. 1700 pg/mL is the upper end of the Elecsys measuring range, so check whether the ADNI UPENN release carries values extrapolated beyond it.

The pipeline now warns about the lost values on every run. It leaves them as they are until this is decided.
